CST2335 Lab 3

Open the CST2335_Lab3 folder in Android Studio.
Allow Gradle to sync, and install Android SDK Platform 35 if Android Studio asks for it.
Create or start an Android emulator, then press Run.

To inspect SharedPreferences, run these commands in Android Studio Terminal:
adb shell
run-as com.example.lab3
cd shared_prefs
cat NamePreferences.xml

Enter a name and press Next before checking the file so the activity has paused and saved the value.
